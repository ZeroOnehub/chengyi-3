# 承艺 3.0 · 初版

可探索、可参与创作的中国非遗数字世界。本版只开放**陶瓷**；其他器物只能预览，界面标为「即将开放」。流程到分享为止，个人场馆以后再做。

视觉以《承艺-代码实现交接包》的四张定图和《陶瓷篇章》九张图为准：墨青底色、低饱和青绿、少量暖金。1.0 版里的画风和元素都没有沿用。

## 怎么打开

- 双击 `start.command`。浏览器会自动打开 `http://localhost:5180`，关掉终端窗口就停止预览。
- 也可以在本目录执行 `python3 -m http.server 5180`，再打开上面的地址。
- 不能直接双击 `index.html`：浏览器不允许本地文件加载 JS 模块，也不允许读取图片像素（粒子要用到）。
- 需要支持 WebGL 的新版 Chrome、Edge 或 Safari。按桌面 1440×900 和 1280×800 设计，窄屏只做了基本适配。

## 完整流程

| 场景 | 看到什么 | 怎么操作 |
| --- | --- | --- |
| 序章 | 暗青星尘背景。光点在呼吸，金尘缓慢漂浮。「万千手艺，由此生光」逐字显现 | 叙事结束后出现「寻光入境」，点它或向下滚动入场。右上角可以开关声音、切换动态效果、跳过 |
| 光核过场 | 即梦生成的过场视频：光核扩散，穿行，落到山河 | 只播放一次，可以跳过。播放失败时直接进入地图 |
| 山河地图 | 地形、雾、器物都在同一坐标系里。金色光点沿河道由远向近流动，移动鼠标有短拖尾 | 拖动平移，滚轮或 ＋/－ 缩放（以鼠标为中心，有边界）。悬停器物显示名称和开放状态。拖动不会误触器物 |
| 器物近景 | 中央只有一件实体器物，左右两件是金色粒子轮廓 | 点左右两侧切换：旧实体散成粒子退到侧边，新器物由粒子聚合成实体，镜头跟着横移。也可以用 ← →。Esc 或左上角返回地图，返回时恢复原来的视角 |
| 陶瓷篇章 | 八幕连续滚动：择土、练泥、成形、施釉（远景推到特写，三条引线）、入窑（光环）、成器（金点）、归土（从右向左碎裂，落成土堆）、承艺（空台上堆土，流程线依次出现） | 滚轮、触控板或方向键推进，向上滚动可以回看。右侧小点可以跳到某一幕，顶部「跳过，直接创作」直接进工作台 |
| 工作台 | 青瓷云纹瓶的三维模型放在青铜圆台上 | 三步：器型（4 种基本形，加宽窄、高矮）、釉色（6 种，亮釉或润釉，可加开片）、纹样（云纹、缠枝莲、海水、素面，4 种纹色）。拖动旋转，滚轮调远近，可以撤销和重做，草稿自动保存在本机 |
| AI 助手 | 底部输入框，例如「想要一只修长的天青瓶，配缠枝莲」 | 先给出建议，确认后才修改作品。「给我灵感」会推荐一组搭配 |
| 入窑 · 分享 | 升温、窑火、还原、开窑，然后命名、落款 | 生成 1080×1350 的分享图。可以保存图片、复制文案，支持时还能调用系统分享。之后可以再做一件，或回到山河 |

**直达地址**（评审和截图用，会跳过序章）：`#map`、`#object`、`#object?id=papercut`、`#chapter`、`#chapter?p=0.45`（停在篇章 45% 处）、`#workbench`。

## 模拟边界：哪些是真的，哪些还没做

- **AI 是演示版**：按关键词理解用户的话，没有接入大模型，界面上写明了。接入方法：设置 `window.CHENGYI_AI_ENDPOINT = 'https://…'`。前端会 POST `{ text, work }`，后台返回 `{ reply, patch }`。`patch` 的字段同 `js/data.js` 里的 `DEFAULT_WORK`。请求失败或超时（15 秒）时，自动退回关键词规则。
- **作品只存在本机**：草稿和落款名保存在浏览器的 localStorage 里，没有账号和云端，也没有公开分享链接。
- **其他器物只能预览**：人偶、团花纹饰、花丝饰件、编篮的名称都是按外观起的，**没有核实过**，界面上标了「示意」。近景中央这四件用的是地图上的小图放大，比较模糊，需要补高清素材。
- **器型变化是近似效果**：在原模型的轮廓上做径向变形，不是重新建模。缠枝莲、海水、开片是程序绘制的纹样。
- **陶瓷篇章是 2.5D 分层**：没有分层源文件，所以文字、主体是从整图里抠出来的；主体移走后露出的背景是算法补的，主体离场时能看到一团柔和的雾。泥团揉压、瓶体转面也是用分层变形和光影模拟的，不是真实转面。

## 目录

```
index.html            所有场景的结构
css/main.css          样式；颜色、字体、时长等变量在 :root
js/main.js            入口：场景切换、顶部控件、声音与动态设置、直达地址
js/data.js            器物数据（地图锚点、近景素材、开放状态）、光河路径、篇章文案、工作台选项
js/prologue.js        序章待机动效与过场视频
js/map.js             地图拖动、缩放、热点，光河流光，雾，拖尾
js/closeup.js         器物近景：粒子采样，实体与粒子互相转换，左右切换
js/chapter.js         陶瓷篇章：滚动时间轴、八幕编排、引导光点、破碎与堆土
js/workbench.js       工作台：three.js 场景、GLB 变形、釉色与纹样贴图、入窑、分享图
js/ai.js              AI 助手（关键词规则，以及大模型接口的预留位置）
js/share.js           分享页
js/sound.js           WebAudio 合成的环境声，不需要音频文件
js/vendor/            three.js r160（本地文件，不依赖 CDN）
assets/               处理后的素材（见下）
tools/prep_assets.py  素材处理脚本：从交接文件夹重新生成 assets/story 和 assets/img
tests/flow.html       端到端流程测试，33 项
```

## 素材来源与处理

- `assets/img/`：序章、地图、近景的背景，以及近景分层和五件器物，取自《承艺-代码实现交接包-樊烨》，转成 JPEG 或压缩过的 PNG。
- `assets/story/`：陶瓷篇章 1–9 图。去掉了烘焙在图里的文字（改成网页文字）；主体用 GrabCut 抠出；主体移走后的背景用 Telea 修补。成品瓶取自 `ChatGPT 图像 2026年10月18日 16_31_03.png`。
- `assets/model/celadon-vase.glb`：`青瓷云纹瓶-无背景-自然釉面.glb`。
- `assets/video/enter.mp4`：即梦生成的入场视频，重新编码过（16MB 压到 3.4MB）。

重新生成素材：`python3 tools/prep_assets.py <承艺3.0 文件夹路径>`。需要 pillow、numpy、scipy、opencv-python-headless。

**开源组件**：只用了 three.js r160（MIT），包括 GLTFLoader 和 RoomEnvironment。规格里提到的 Panzoom、tsParticles、Anime.js 都评估过：地图拖缩、粒子、时间轴的需求都很窄，自己写的代码更少，也更容易贴合画面，所以没有引入。

## 测试

启动预览后打开 `http://localhost:5180/tests/flow.html`。它会自动走一遍完整流程：序章 → 过场 → 地图缩放 → 近景切换（包括连续点击）→ 返回地图 → 篇章滚动和回看 → 工作台手动操作、撤销重做 → AI 建议 → 入窑 → 分享。顶部显示 `RESULT 33/33` 表示全部通过。
